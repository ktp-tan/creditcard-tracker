# 💳 คู่มือการติดตั้งระบบ Credit Card Tracker (Google Apps Script Web App)

ระบบบันทึกรายการใช้จ่ายบัตรเครดิตผ่านเว็บแอพบนมือถือ เชื่อมต่อ Google Sheet แบบ Real-time ตัดรอบทุกวันที่ 5 พร้อมระบบคำนวณรอบบิลและแก้ไข/ลบรายการ

---

## 🌟 ฟังก์ชันหลัก
1. **การแสดงผลรอบบิล (Billing Cycle)**:
   - **รอบก่อนหน้า (อยู่ด้านบนสุด)**: แสดงช่วงวันที่, ยอดรวม, ยอด Personal (เดี่ยว), และยอด Sharing (หาร)
   - **รอบปัจจุบัน**: แสดงช่วงวันที่, ยอดรวม, ยอด Personal (เดี่ยว), และยอด Sharing (หาร)
   - ตัดรอบอัตโนมัติทุกวันที่ 5 (เช่น 5 ก.ย. - 4 ต.ค. เป็น 1 รอบ)
2. **การบันทึกรายการใหม่ (Quick Input)**:
   - กรอกยอดเงิน (numeric keypad ใช้ง่ายบนมือถือ)
   - Memo / บันทึกช่วยจำ
   - วันที่ทำรายการ (Default เป็นวันนี้ สามารถเปลี่ยนได้)
   - สลับประเภท Personal / Sharing ได้ด้วยการแตะปุ่มเดียว
3. **ระบบจัดการรายการ (Edit & Delete)**:
   - แสดงรายการล่าสุดทั้งหมด
   - ✏️ **แก้ไข**: ดึงข้อมูลเดิมมาแก้แล้วกดอัปเดตลง Sheet ทันที
   - 🗑️ **ลบ**: มี Pop-up ยืนยันก่อนลบเพื่อความปลอดภัย

---

## 🚀 ขั้นตอนการติดตั้ง (ใช้เวลาเพียง 3-5 นาที)

### ขั้นตอนที่ 1: สร้าง Google Sheet ใหม่
1. ไปที่ [Google Sheets](https://sheets.new) เพื่อสร้างสเปรดชีตใหม่
2. ตั้งชื่อไฟล์ตามต้องการ เช่น `Credit Card Tracker`

---

### ขั้นตอนที่ 2: นำโค้ดไปใส่ใน Google Apps Script
1. ที่เมนูด้านบนของ Google Sheet ให้คลิก **ส่วนขยาย (Extensions)** $\rightarrow$ **Apps Script**
2. ในหน้าต่าง Apps Script จะมีไฟล์ชื่อ `Code.gs`:
   - ลบโค้ดเดิมออกทั้งหมด
   - เปิดไฟล์ [`Code.gs`](file:///c:/Users/UsEr/Desktop/Projects/CreditCard_Txns_Rec/Code.gs) ในโปรเจกต์นี้ คัดลอกโค้ดทั้งหมดมาวางแทนที่
3. สร้างไฟล์หน้าเว็บ `Index.html`:
   - มองหาเครื่องหมายบวก **(+)** ข้างๆ คำว่า "ไฟล์" (Files) ทางแถบซ้าย
   - เลือก **HTML**
   - ตั้งชื่อไฟล์ว่า `Index` (ระบบจะใส่นามสกุล `.html` ให้อัตโนมัติ)
   - ลบโค้ดเดิมออก แล้วเปิดไฟล์ [`Index.html`](file:///c:/Users/UsEr/Desktop/Projects/CreditCard_Txns_Rec/Index.html) ในโปรเจกต์นี้ คัดลอกโค้ดทั้งหมดมาวาง
4. กดรูป **💾 บันทึกโปรเจกต์ (Save project)** ด้านบน

---

### ขั้นตอนที่ 3: Deploy (เผยแพร่เป็น Web App)
1. คลิกปุ่มสีน้ำเงินมุมบนขวา **ทำให้ใช้งานได้ (Deploy)** $\rightarrow$ **การทำให้ใช้งานได้ใหม่ (New deployment)**
2. คลิกรูปฟันเฟือง ⚙️ ด้านซ้าย เลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description)**: `Credit Card Tracker v1`
   - **ดำเนินการในฐานะ (Execute as)**: `ฉัน (Me)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: `ทุกคน (Anyone)` *(เพื่อให้เปิดใช้งานบนมือถือได้สะดวกโดยไม่ต้องติดปัญหา login ซ้อนบัญชี)*
4. คลิก **ทำให้ใช้งานได้ (Deploy)**
5. ครั้งแรกระบบจะให้ยืนยันสิทธิ์เข้าถึง (Authorize Access):
   - คลิก **ตรวจสอบสิทธิ์ (Review permissions)**
   - เลือกบัญชี Google ของคุณ
   - หากขึ้นเตือน *"Google ยังไม่ได้ยืนยันแอปนี้"* ให้คลิก **ขั้นสูง (Advanced)** $\rightarrow$ คลิก **ไปที่ ... (ไม่ปลอดภัย) / Go to ... (unsafe)**
   - คลิก **อนุญาต (Allow)**
6. เมื่อเสร็จสิ้น คุณจะได้รับ **URL ของเว็บแอป (Web app URL)**
   - คัดลอก URL นี้เก็บไว้ สำหรับเปิดใช้งานบนมือถือ

## 📱 วิธีทำเป็นไอคอนแอพบนหน้าจอมือถือ (Add to Home Screen)

### สำหรับ iPhone (iOS / Safari)
1. เปิดลิงก์ Web app URL ในแอพ **Safari**
2. กดปุ่ม **แชร์ (Share)** (ไอคอนสี่เหลี่ยมมีลูกศรชี้ขึ้นที่แถบด้านล่าง)
3. เลื่อนลงมาเลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. ตั้งชื่อไอคอนตามต้องการแล้วกด **เพิ่ม (Add)**

### สำหรับ Android (Chrome)
1. เปิดลิงก์ Web app URL ในแอพ **Google Chrome**
2. แตะปุ่มเมนู **จุด 3 จุด** ที่มุมขวาบน
3. เลือก **"เพิ่มลงในหน้าจอหลัก" (Add to Home screen)** หรือ **"ติดตั้งแอป" (Install app)**
4. กดยืนยัน
